# LEJ Session Board, CLI fork

Forked into the swarph plugin from [lej-claude-session-board](https://github.com/justfinethanku/lej-claude-session-board) by Jonathan Edwards ([Limited Edition Jonathan](https://limitededitionjonathan.com)). MIT. The LICENSE file in this directory is the upstream license, unchanged.

The page template, the demo data, and `references/data-schema.md` are the upstream files. This fork changes the instructions and the coordination rule so a Claude Code CLI session can build the board with `ListAgents`, `SendMessage`, local transcript tails, and the swarph board. It does not archive sessions.

Made by Jonathan Edwards. The CLI adaptation is for the swarph fleet.
